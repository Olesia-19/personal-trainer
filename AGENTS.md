# Personal Trainer Project Rules

## Tech Stack

- Next.js (App Router)
- TypeScript
- CSS Modules (no Tailwind)

## Code Style

- Functional components only
- Arrow functions
- Clean and readable code

## Structure

- /app — pages
- /components — reusable UI
- /styles — CSS modules

## UI Guidelines

- Clean, minimal design
- Fitness / personal trainer aesthetic
- Mobile-first

## AI Instructions

- Do not use Tailwind
- Do not overcomplicate logic
- Always explain what you generate
